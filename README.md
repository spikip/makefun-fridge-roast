## About this entry

The line is a midnight fridge raid in miniature, which is exactly
the joke the bounty asks for. It opens by addressing the fridge
directly, "Dear fridge,", so the reader gets the roast before the
punchline even arrives. Then it reframes the fridge at two in the
morning: not a snack bar, but a crime scene with a light inside, and
the narrator is the repeat offender standing in their underwear.
That is a midnight raid in one sentence, a familiar guilty habit
turned into a police report everyone recognises at once. The line is
a single sentence, it needs no explanation, and it stays well inside
the two hundred character cap. The program holds the line, checks it
against that cap, and writes it to /output/entry.txt exactly as the
bounty requires.

## Run it

```sh
python3 main.py
```
